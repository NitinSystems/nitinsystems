Google Gemini Flash-Lite · Node Gateway · Make.com · HubSpot

AI-Assisted Inbound Qualification & Operations System

A sub-2-second edge-deployed consultative AI system that evaluates B2B workflow friction, diagnoses CRM data sync bottlenecks, enforces security boundaries, and automates Make.com lead ingestion 24/7.

01. The Problem

Static web forms suffer 80%+ drop-off from busy founders, while generic chatbots frustrate high-ticket buyers with canned loops. Inquiries lacked structured diagnosis before reaching sales calendars.

02. Solution Strategy

Deploy a fast, edge-hosted consultative AI model trained strictly on B2B systems engineering. Use intent routing to answer architectural questions, guide prospects into an in-chat qualification card, and push structured payloads into automated downstream CRM workflows.

03. System Built

Private Node.js proxy isolating Gemini Flash-Lite credentials; sliding context memory; zero-dox security boundary shield; in-modal qualification card; Make.com webhook synchronizing lead data across Airtable, HubSpot CRM, and Slack alerts.

04. Delivered & Verified

Two 16:9 architecture topology diagrams, 12 verified test assets, complete adversarial prompt-injection test suite, and active 24/7 deployment operating live on this website.

GoHighLevel · Gmail · Google Calendar

Lead Capture to Booking System

A direct system build connecting web intake forms, automated SMS and email reminder sequences, and 2-way Google Calendar synchronization for an active consulting and service practice. Designed to eliminate manual scheduling drag and recover warm inquiries before they drop off.

01. The Problem

Prospective client inquiries sat unaddressed in generic inbox folders. Back-and-forth email scheduling created booking delays of 24-48 hours, leading to a 35% no-show rate and lost warm sales conversations.

02. Solution Strategy

Replace manual inbox monitoring with an automated intake funnel. Capture prospect parameters directly into GoHighLevel, open an immediate interactive booking calendar, and enforce timed reminder sequences across multiple channels.

03. System Built

High-speed intake form routed through a GoHighLevel workflow engine; 2-way synchronized Google Calendar booking widget; automated 24-hour and 1-hour pre-meeting SMS and email confirmations with instant cancellation handling.

04. Delivered & Verified

Delivered complete architecture documentation, operational SOP runbooks, client admin handoff walkthrough, and verified live booking pipeline processing real client appointments.

Self-Initiated Build Data Deduplication & CRM Routing
Make.com · Airtable · HubSpot CRM · Webhooks

Lead Intake & Duplicate Verification System

An engineered multi-tool intake pipeline evaluating raw webhook payloads against an Airtable master table to enforce deduplication and record updates before synchronizing to HubSpot CRM.

01. The Problem

Repeated web form submissions created redundant contact records in HubSpot CRM. Sales representatives contacted the same prospect multiple times with conflicting messaging, corrupting deal attribution and pipeline reporting.

02. Solution Strategy

Place a deterministic middleware verification layer between raw web intake and CRM storage. Intercept incoming payloads, normalize contact identifiers, and run lookup verification against a central record store before any CRM write.

03. System Built

Make.com webhook listener normalizing email strings and phone digits; Airtable search formula querying existing profiles; conditional router executing either a HubSpot contact update or creating a verified new lead.

04. Delivered & Verified

Engineered blueprint specification PDF, exported Make.com scenario JSON file, normalized data dictionary, and 100% verified test logs across clean submissions and simulated duplicate submissions.

Architecture Case Study AI-Assisted Customer Journey & Recovery
Make.com · Make AI Agent · Airtable

AI Customer Journey Operations & Recovery System

A 7-scenario operational architecture supported by 5 linked Airtable tables demonstrating how middleware orchestration, relational records, and AI context analysis monitor lifecycle states, identify stalled opportunities, and trigger recovery actions.

01. The Problem

High-value prospects frequently stall in mid-funnel stages (post-proposal or contract review) without automated visibility. Sales leadership relied on manual spreadsheet audits to spot dying pipeline opportunities.

02. Solution Strategy

Build an automated journey tracker using state-change listeners. Trigger scheduled cron checks for inactive opportunities, feed contextual interaction history into an AI evaluation engine, and produce structured recovery recommendations.

03. System Built

7 distinct Make.com automation scenarios connected to 5 relational Airtable tables; automated staleness monitor flagging deals inactive for 72+ hours; Make AI reasoning agent assessing objection history and dispatching recovery tasks.

04. Delivered & Verified

Comprehensive 30+ page architecture case study document, complete scenario execution maps, relational schema diagram, and end-to-end sandbox execution logs proving automatic recovery dispatch.
